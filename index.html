What changed in v3

  • LCD wiring switched from parallel 4-bit to I2C — down to two signal wires.
  • The web UI is noticeably more responsive, with input lag largely eliminated.
  • Wi-Fi loss is now shown on the LCD and recovers automatically.
  • More stable overall, with clamped inputs and reduced memory churn.
